## Tasks

1. **Number Game** – Guess the number game.  
   **Sample Output:**
   Guess the number between 1 and 100:
   Enter your guess: 45  
   Too low! Try again.  
   Enter your guess: 78  
   Too high! Try again.  
   Enter your guess: 62  
   Correct! You guessed the number.  

2. **Student Grade Calculator** – Calculates grades based on marks.  
   **Sample Output:**
   Enter marks for 3 subjects:  
   Math: 80  
   Science: 70  
   English: 90  
   Total = 240  
   Average = 80  
   Grade = A  

3. **ATM Interface** – Simulates ATM operations (deposit, withdraw, balance).  
   **Sample Output:**
   Welcome to the ATM  
   1. Deposit  
   2. Withdraw  
   3. Check Balance  
   Enter choice: 1  
   Enter amount to deposit: 500  
   Deposit successful! Balance = 1500  

4. **Quiz Application** – Multiple-choice quiz with timer.  
   **Sample Output:**
   Question 1: What is the capital of India?  
   A) Delhi  
   B) Mumbai  
   C) Kolkata  
   D) Chennai  
   Enter your answer: A  
   Correct!  

5. **Course Registration System** – Allows students to register for courses.  
   **Sample Output:**
   Available Courses:  
   1. Java Programming  
   2. Data Structures  
   3. Database Systems  
   Enter course number to register: 1  
   Student registered for Java Programming successfully!

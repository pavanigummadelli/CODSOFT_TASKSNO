# CODSOFT Internship Tasks

This repository contains Java projects completed as part of my CODSOFT internship.

## Tasks
1. **Number Game** – Guess the number game.
2. **Student Grade Calculator** – Calculates grades based on marks.
3. **ATM Interface** – Simulates ATM operations (deposit, withdraw, balance).
4. **Quiz Application** – Multiple-choice quiz with timer.
5. **Course Registration System** – Allows students to register for courses.

## How to Run
- Clone the repo:  
  `git clone https://github.com/pavanigummadelli/CODSOFT_TASKSNO.git`
- Navigate into the folder:  
  `cd CODSOFT_TASKSNO`
- Compile:  
  `javac FileName.java`
- Run:  
  `java FileName`

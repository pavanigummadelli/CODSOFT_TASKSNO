
## How to Run

1. Clone the repository:
 git clone https://github.com/pavanigummadelli/CODSOFT_TASKSNO.git

2. Navigate into the folder:
cd CODSOFT_TASKSNO

3. Compile the Java file:
javac FileName.java

4. Run the program:
java FileName

👉 Replace `FileName.java` with the actual task file you want to run:
- `NumberGame.java`
- `StudentGradeCalculator.java`
- `ATMApp.java`
- `QuizApplication.java`
- `CourseRegistrationSystem.java`
